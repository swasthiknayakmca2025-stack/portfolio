# Swasthik Nayak — Portfolio Website

A modern, responsive, and interactive developer portfolio showcasing the skills, projects, education, and credentials of **Swasthik Nayak** (MCA Candidate @ Poornaprajna Institute of Management, Udupi & IIT Kharagpur NPTEL Elite Medalist).

---

## 🌟 Highlights & Features

- **Hero & Identity**: Dynamic typing role animation, quick stats, interactive contact pills, and profile photo extracted directly from the CV.
- **Skills Matrix**: Categorized filtering (*Programming & Core CS*, *Web & Frontend*, *Backend & Database*, *Professional & Leadership*) with progress indicators.
- **Featured Project — Restaurant Management System (RMS)**:
  - Architecture breakdown featuring real-time table reservations, order tracking pipelines, and automated GST billing.
  - Role-Based Access Control (RBAC) tiers: Admin, Waiter, and Kitchen staff.
  - **Live Interactive Prototype Simulator**: An embedded interactive modal where visitors can simulate table status toggles, place orders directly to the Kitchen Display System (KDS), and calculate GST invoices.
- **Developer Terminal Emulator**: An interactive shell (`swasthik@dev:~$`) supporting commands like `help`, `skills`, `rms`, `cert`, `education`, `contact`, `hire`, and `clear`.
- **Certifications & Honors**: Highlighting the **NPTEL Elite Medal in Data Structures and Algorithms in Python** issued by **IIT Kharagpur**.
- **Leadership**: Showcasing 3 consecutive years as **Cultural Secretary at Alvas College** and 1 year as an active **NSS Volunteer**.
- **Theme System**: Seamless switch between Dark Mode and Light Mode with persistence via `localStorage`.
- **Direct Connect**: One-click clipboard copy for phone and email, direct WhatsApp chat integration, and downloadable PDF resume.

## 🚀 Running Locally

No dependencies or build steps are required. Simply open `index.html` in any modern web browser or serve it with Python:

```bash
# Start a local web server
python -m http.server 3000
```

Then visit `http://localhost:3000` in your web browser.
